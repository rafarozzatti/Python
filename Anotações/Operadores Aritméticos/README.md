# Operadores Aritméticos

### Tipos de Operadores:
1. **Adição: +**
2. **Subtração: -**
3. **Multiplição: ***
4. **Divisão: /**
5. **Potência: ****
6. **Divisão Inteira: //**
7. **Resto da Divisão: %**

### Exemplos:
1. **Adição: 5 + 2 = 7**
2. **Subtração: 5 - 2 = 3**
3. **Multiplição: 5 * 2 = 10**
4. **Divisão: 5 / 2 = 2.5**
5. **Potência: 5 ** 2 = 25**
6. **Divisão Inteira: 5 // 2 = 2**
7. **Resto da Divisão: 5 % 2 = 1**

### Ordem de Precedência:
1. **Parênteses: ()**
2. **Potência: ****
3. **Multiplição: *, Divisão: /, Divisão Inteira: //, Resto da Divisão: %**
4. **Adição: +, Subtração: -**
