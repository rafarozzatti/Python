## Exercício 1

```python
dobro = lambda x : x * 2

print(dobro(8))
```

## Exercício 2

```python
somar = lambda a, b : a + b

print(somar(15, 25))
```

## Exercício 3

```python
verificar_idade = lambda x : 'Maior de idade' if x >= 18 else 'Menor de idade'

print(verificar_idade(16))
```

## Exercício 4

## Exercício 5

## Exercício 7

```python
preco_com_desconto = lambda preco, desconto : preco - (preco * (desconto / 100))

print(preco_com_desconto(200, 15))
```

## Exercício 8

