# **Exercícios de Tratamento de entradas inválidas**

## **Exercício 1**

1. Solicite a idade de uma pessoa.
2. Se a idade for negativa, exiba `Erro: idade inválida`.
3. Caso contrário, exiba `Idade registrada`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-1)

## **Exercício 2**

1. Solicite o preço de um produto.
2. Se o preço for menor ou igual a zero, exiba `Erro: preço inválido`.
3. Caso contrário, exiba `Preço registrado`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-2)

## **Exercício 3**

1. Solicite a quantidade de produtos.
2. Se a quantidade for menor ou igual a zero, exiba `Erro: quantidade inválida`.
3. Caso contrário, exiba `Quantidade registrada`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-3)

## **Exercício 4**

1. Solicite uma nota.
2. Se ela for menor que zero ou maior que dez, exiba `Erro: nota inválida`.
3. Caso contrário, exiba `Nota registrada`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-4)

## **Exercício 5**

1. Solicite o salário de um funcionário.
2. Se o salário for menor ou igual a zero, exiba `Erro: salário inválido`.
3. Caso contrário, exiba `Salário registrado`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-5)

## **Exercício 6**

1. Solicite dois números.
2. Verifique se o segundo número é igual a zero.
3. Se for, exiba `Erro: não é possível dividir por zero`.
4. Caso contrário, realize a divisão e apresente o resultado.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-6)

## **Exercício 7**

1. Solicite o valor de uma compra e o percentual de desconto.
2. Se o valor da compra for menor ou igual a zero, exiba `Erro: valor da compra inválido`.
3. Se o desconto for menor que zero ou maior que 100, exiba `Erro: percentual de desconto inválido`.
4. Caso contrário, calcule e apresente o valor final.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-7)

## **Exercício 8**

1. Solicite a quantidade atual em estoque e a quantidade que será retirada.
2. Se qualquer quantidade for menor ou igual a zero, exiba `Erro: quantidade inválida`.
3. Se a retirada for maior que o estoque disponível, exiba `Erro: estoque insuficiente`.
4. Caso contrário, calcule e apresente o estoque restante.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-8)

## **Exercício 9**

1. Solicite o nome e a idade de uma pessoa.
2. Se o nome estiver vazio, exiba `Erro: nome não informado`.
3. Se a idade for negativa, exiba `Erro: idade inválida`.
4. Caso contrário, exiba `Cadastro realizado com sucesso`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-9)

## **Exercício 10**

1. Solicite o preço de um produto, a quantidade comprada e o percentual de desconto.
2. Verifique se o preço e a quantidade são maiores que zero.
3. Verifique se o desconto está entre 0 e 100.
4. Se alguma informação for inválida, apresente a mensagem correspondente.
5. Caso todas sejam válidas, calcule o total da compra, aplique o desconto e apresente o valor final.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-10)
