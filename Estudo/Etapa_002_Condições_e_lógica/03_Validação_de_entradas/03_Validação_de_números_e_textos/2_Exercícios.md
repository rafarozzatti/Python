# **Exercícios de Validação de números e textos**

## **Exercício 1**

1. Solicite um número inteiro.
2. Verifique se ele está entre 1 e 50, incluindo os limites.
3. Exiba `Número aceito` ou `Número fora do intervalo`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-1)

## **Exercício 2**

1. Solicite o preço de um produto.
2. Verifique se o preço é maior que zero.
3. Exiba `Preço válido` ou `Preço inválido`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-2)

## **Exercício 3**

1. Solicite uma nota decimal.
2. Verifique se ela está entre 0 e 10, incluindo os limites.
3. Exiba `Nota válida` ou `Nota inválida`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-3)

## **Exercício 4**

1. Solicite o nome de uma pessoa.
2. Verifique se o texto está vazio.
3. Exiba `Nome não informado` ou `Nome informado`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-4)

## **Exercício 5**

1. Solicite o nome de uma pessoa.
2. Utilize `strip()` para verificar se o texto contém apenas espaços ou está vazio.
3. Exiba `Nome não informado` ou `Nome informado`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-5)

## **Exercício 6**

1. Solicite uma senha.
2. Utilize `len()` para verificar se ela possui pelo menos 8 caracteres.
3. Exiba `Senha aceita` ou `Senha muito curta`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-6)

## **Exercício 7**

1. Solicite um endereço de e-mail.
2. Utilize `in` para verificar se existe o caractere `@`.
3. Exiba `E-mail contém @` ou `E-mail não contém @`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-7)

## **Exercício 8**

1. Solicite um código de identificação.
2. Utilize `len()` para verificar se ele possui exatamente 6 caracteres.
3. Exiba `Código aceito` ou `Código inválido`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-8)

## **Exercício 9**

1. Solicite o nome completo de uma pessoa.
2. Utilize `in` para verificar se existe um espaço no texto.
3. Exiba `Nome completo informado` ou `Informe nome e sobrenome`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-9)

## **Exercício 10**

1. Solicite o nome, a idade e o salário de um funcionário.
2. Verifique se o nome não está vazio, considerando também os espaços.
3. Verifique se a idade está entre 18 e 65 anos, incluindo os limites.
4. Verifique se o salário é maior que zero.
5. Se todas as condições forem verdadeiras, exiba `Cadastro válido`. Caso contrário, exiba `Cadastro inválido`.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-10)
