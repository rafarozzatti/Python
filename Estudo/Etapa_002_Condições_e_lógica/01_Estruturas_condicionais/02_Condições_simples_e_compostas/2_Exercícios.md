# **Exercícios de Condições Simples e Compostas**

## **Exercício 1**

Crie um programa que:

1. Solicite a idade do usuário.
2. Verifique se a idade é maior ou igual a `18`.
3. Utilize uma condição simples com `if`.
4. Exiba `"Maior de idade"` caso a condição seja verdadeira.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-1)

## **Exercício 3**

Crie um programa que:

1. Solicite a idade do usuário.
2. Solicite se ele possui habilitação (`True` ou `False`).
3. Verifique se a idade é maior ou igual a `18` e se possui habilitação.
4. Utilize o operador `and`.
5. Exiba `"Pode dirigir"` caso as duas condições sejam verdadeiras.

## **Exercício 4**

Crie um programa que:

1. Solicite o valor de uma compra.

3. Verifique se o cliente é VIP ou se a compra é superior a `500`.
4. Utilize o operador `or`.
5. Exiba `"Desconto disponível"` caso pelo menos uma condição seja verdadeira.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-4)

## **Exercício 10**

Último exercício deste assunto!

Crie um programa que:

1. Solicite a idade de um candidato.
2. Solicite se ele possui experiência (`True` ou `False`).
3. Verifique se o candidato tem idade entre `18` e `35` anos e possui experiência, ou se tem mais de `35` anos e possui experiência.
4. Utilize os operadores `and` e `or`, organizando as condições com parênteses.
5. Exiba `"Candidato atende aos critérios"` caso a condição seja verdadeira.
