# **Resolução dos Exercícios de Estruturas Condicionais**

## **Exercício 1**

```python
idade = int(input('Digite sua idade: '))

if idade >= 18:
    print('Maior de idade')
```

## **Exercício 2**

```python
numero = int(input('Digite um número: '))

if numero > 0:
    print('Número positivo')
```

## **Exercício 3**

```python
idade = int(input('Digite sua idade: '))

if idade >= 18:
    print('Maior de idade')
else:
    print('Menor de idade')
```

## **Exercício 4**

```python
numero = int(input('Digite um número: '))

if numero % 2 == 0:
    print('Número par')
else:
    print('Número ímpar')
```

## **Exercício 5**

```python
nota = float(input('Digite sua nota: '))

if nota >= 7:
    print('Aprovado')
else:
    print('Reprovado')
```

## **Exercício 6**

```python
idade = int(input('Digite sua idade: '))

if idade < 12:
    print('Criança')
elif idade < 18:
    print('Adolescente')
else:
    print('Adulto')
```

## **Exercício 7**

```python
nota = float(input('Digite sua nota: '))

if nota >= 9:
    print('Excelente')
elif nota >= 7:
    print('Bom')
elif nota >= 5:
    print('Em recuperação')
else:
    print('Reprovado')
```

## **Exercício 8**

```python
numero = int(input('Digite um número: '))

if numero > 0:
    print('Número positivo')
elif numero < 0:
    print('Número negativo')
else:
    print('Zero')
```

## **Exercício 9**

```python
preco = float(input('Digite o preço do produto: '))

if preco > 100:
    print('Produto caro')
elif preco > 50:
    print('Preço intermediário')
else:
    print('Produto barato')
```
