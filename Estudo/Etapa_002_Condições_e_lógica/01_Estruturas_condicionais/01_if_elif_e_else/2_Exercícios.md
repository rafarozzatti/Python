# **Exercícios de Estruturas Condicionais**

## **Exercício 1**

Crie um programa que:

1. Solicite a idade do usuário utilizando `input()`.
2. Converta a idade para `int`.
3. Utilize `if` para verificar se a idade é maior ou igual a `18`.
4. Exiba `"Maior de idade"` caso a condição seja verdadeira.

Resolução

## **Exercício 3**

## **Exercício 6**

Crie um programa que:

1. Solicite a idade do usuário.
2. Utilize `if` para verificar se a idade é menor que `12`.
3. Utilize `elif` para verificar se a idade é menor que `18`.
4. Utilize `else` para tratar as demais idades.
5. Exiba `"Criança"`, `"Adolescente"` ou `"Adulto"`.

Resolução

Resolução

## **Exercício 9**

Resolução
