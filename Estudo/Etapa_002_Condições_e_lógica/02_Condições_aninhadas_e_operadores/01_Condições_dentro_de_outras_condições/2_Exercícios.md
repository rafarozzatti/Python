## **Exercícios — Condições aninhadas**

### **Exercício 1**

1. Crie uma variável `idade` com o valor `20`.
2. Verifique se a pessoa é maior de idade.
3. Dentro dessa condição, verifique se ela tem 21 anos ou mais.
4. Exiba uma mensagem diferente para cada situação.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-1)

### **Exercício 2**

1. Crie uma variável `nota` com o valor `8`.
2. Verifique se a nota é maior ou igual a 7.
3. Se for, verifique se é maior ou igual a 9.
4. Exiba uma mensagem indicando se o aluno foi aprovado ou se obteve uma nota excelente.
5. Caso não atinja 7, exiba que foi reprovado.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-2)

### **Exercício 3**

1. Crie uma variável `saldo` com o valor `1000` e outra `compra` com o valor `300`.
2. Verifique se o saldo é suficiente para a compra.
3. Se for, verifique se o saldo é maior que o valor da compra.
4. Exiba mensagens diferentes para cada situação.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-3)

### **Exercício 4**

1. Crie uma variável `temperatura` com o valor `30`.
2. Verifique se a temperatura é maior que 25.
3. Dentro dessa condição, verifique se é maior que 35.
4. Exiba mensagens indicando se a temperatura está elevada ou muito elevada.
5. Caso não ultrapasse 25, informe que a temperatura está normal.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-4)

### **Exercício 5**

1. Crie uma variável `idade` com o valor `17`.
2. Verifique se a pessoa tem 18 anos ou mais.
3. Se tiver, verifique se tem 60 anos ou mais.
4. Exiba uma mensagem para cada faixa etária.
5. Caso seja menor de idade, informe essa situação.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-5)

### **Exercício 6**

1. Crie uma variável `nota` com o valor `6` e outra `frequencia` com o valor `80`.
2. Verifique se a nota é maior ou igual a 5.
3. Dentro dessa condição, verifique se a frequência é maior ou igual a 75.
4. Exiba se o aluno foi aprovado ou reprovado por frequência.
5. Caso a nota seja inferior a 5, informe que foi reprovado por nota.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-6)

### **Exercício 7**

1. Crie uma variável `idade` com o valor `25` e outra `renda` com o valor `3500`.
2. Verifique se a pessoa tem 18 anos ou mais.
3. Se tiver, verifique se a renda é maior ou igual a 3000.
4. Exiba se o crédito foi aprovado ou se a renda é insuficiente.
5. Caso seja menor de idade, informe que não atende ao requisito.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-7)

### **Exercício 8**

1. Crie uma variável `numero` com o valor `10`.
2. Verifique se o número é positivo.
3. Dentro dessa condição, verifique se ele é maior que 5.
4. Exiba mensagens diferentes conforme o resultado.
5. Caso não seja positivo, informe essa situação.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-8)

### **Exercício 9**

1. Crie uma variável `idade` com o valor `22` e outra `possui_ingresso` com o valor `True`.
2. Verifique se a pessoa é maior de idade.
3. Se for, verifique se possui ingresso.
4. Exiba se a entrada está permitida ou se precisa de ingresso.
5. Caso seja menor de idade, informe que a entrada não é permitida.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-9)

### **Exercício 10**

1. Crie uma variável `salario` com o valor `4000` e outra `tempo_empresa` com o valor `3`.
2. Verifique se o salário é maior ou igual a 3000.
3. Dentro dessa condição, verifique se o tempo de empresa é maior ou igual a 2 anos.
4. Exiba se o funcionário atende aos dois requisitos.
5. Caso algum requisito não seja atendido, exiba a mensagem correspondente.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-10)
