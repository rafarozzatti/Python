# Exercícios de Variáveis e atribuição de valores

## Exercício 1

Escreva um programa que:

1. Crie uma variável chamada nome com o texto "Rafael".
2. Crie uma variável chamada cidade com o texto "São Paulo".
3. Exiba o valor de nome.
4. Exiba o valor de cidade.

A saída esperada é:

```
Rafael
São Paulo
```

## Exercício 2

Agora, vamos praticar a atribuição de valores numéricos a variáveis.

Faça o seguinte:

1. Crie uma variável chamada `idade` e atribua a ela o valor inteiro `27`.
2. Crie uma variável chamada `altura` e atribua a ela o valor decimal `1.75`.
3. Crie uma variável chamada `ano_nascimento` e atribua a ela o valor `1999`.
4. Utilize `print()` para exibir o conteúdo das três variáveis, nessa ordem.

Saída esperada:

```
27
1.69
1999
```

## Exercício 3

Neste exercício, vamos praticar a reatribuição de valores: quando uma variável recebe um novo valor.

Faça o seguinte:

1. Crie uma variável chamada `saldo` com o valor `500`.
2. Utilize `print()` para exibir o saldo.
3. Altere o valor de `saldo` para `750`.
4. Utilize `print()` novamente para exibir o novo saldo.

Saída esperada:

```
500
750
```

## Exercício 4

Agora, vamos praticar algo um pouco diferente: utilizar o valor atual de uma variável para calcular seu novo valor.

Faça o seguinte:

1. Crie uma variável chamada `quantidade` com o valor `10`.
2. Atualize `quantidade`, adicionando `5` ao valor que ela já possui.
3. Exiba o valor final utilizando `print()`.

Saída esperada:

```
15
```

## Exercício 5 

Agora, vamos praticar a criação de variáveis com textos e a alteração de seus valores.

Faça o seguinte:

1. Crie uma variável chamada `produto` com o texto `"Teclado"`.
2. Crie uma variável chamada `preco` com o valor `120.50`.
3. Exiba as duas variáveis, nessa ordem.
4. Altere o valor de `produto` para `"Mouse"`.
5. Exiba novamente a variável `produto`.

Saída esperada:

```
Teclado
120.5
Mouse
```

## Exercício 6

Agora, vamos combinar textos e números em diferentes variáveis.

Crie um programa que:

1. Armazene o nome de um funcionário na variável `nome_funcionario`, usando o texto `"Carlos"`.
2. Armazene o departamento na variável `departamento`, usando o texto `"Logística"`.
3. Armazene o salário na variável `salario`, usando o valor `2800`.
4. Exiba o conteúdo das três variáveis, nessa ordem, cada uma em uma linha.

Saída esperada:

```
Carlos
Logística
2800
```

## Exercício 7

Uma empresa possui um estoque de produtos. Você deverá atualizar a quantidade disponível após uma entrada de mercadorias.

Faça o seguinte:

1. Crie a variável `estoque` com o valor `100`.
2. Adicione `35` à quantidade existente, atualizando a própria variável `estoque`.
3. Retire `20` unidades do estoque, atualizando novamente a mesma variável.
4. Exiba o valor final de `estoque`.

Saída esperada:

```
115
```

## Exercício 8

Uma loja vende produtos e precisa calcular o valor total de uma compra.

Faça o seguinte:

1. Crie a variável `preco_unitario` com o valor `25`.
2. Crie a variável `quantidade_comprada` com o valor `4`.
3. Crie a variável `total_compra`, calculando o preço unitário multiplicado pela quantidade comprada.
4. Exiba o valor de `total_compra`.

Saída esperada:

```
100
```

## Exercício 9

Uma empresa precisa calcular o faturamento de suas vendas após uma alteração na quantidade de produtos vendidos.

Faça o seguinte:

1. Crie a variável `preco_produto` com o valor `50`.
2. Crie a variável `quantidade_vendida` com o valor `10`.
3. Crie a variável `faturamento` multiplicando o preço do produto pela quantidade vendida.
4. Aumente `quantidade_vendida` em `5`, atualizando a própria variável.
5. Recalcule `faturamento` usando os valores atuais de `preco_produto` e `quantidade_vendida`.
6. Exiba o valor final de `faturamento`.

Saída esperada:

```
750
```

## Exercício 10

Este é o último exercício da etapa de variáveis e atribuição de valores. Vamos reunir os conceitos que você praticou.

Uma loja precisa registrar e atualizar suas vendas.

Crie um programa que:

1. Crie `nome_produto` com o texto `"Monitor"`.
2. Crie `preco_unitario` com o valor `800`.
3. Crie `quantidade_vendida` com o valor `3`.
4. Calcule `faturamento` multiplicando o preço unitário pela quantidade vendida.
5. Aumente `quantidade_vendida` em `2`.
6. Recalcule `faturamento` com a nova quantidade.
7. Exiba, nessa ordem, o nome do produto, o preço unitário, a quantidade vendida atualizada e o faturamento final, cada um em uma linha.

Saída esperada:

```
Monitor
800
5
4000
```
