# Exercícios de Operadores de atribuição

## Exercício 1

Vamos começar com o operador mais básico e depois aumentar a dificuldade gradualmente.

Crie um programa que:

1. Crie a variável `quantidade` com o valor `20`.
2. Depois, atribua o valor `35` à mesma variável usando `=`.
3. Imprima `quantidade`.

Qual será o valor impresso?

## Exercício 2

Crie um programa que:

1. Crie a variável `pontos` com o valor `10`.
2. Utilize `+=` para adicionar `5` à variável `pontos`.
3. Imprima `pontos`.

Saída esperada:

```
15
```

## Exercício 3

Crie um programa que:

1. Crie a variável `estoque` com o valor `50`.
2. Utilize `-=` para subtrair `12` da variável `estoque`.
3. Imprima `estoque`.

Saída esperada:

```
38
```

## Exercício 4

Crie um programa que:

1. Crie a variável `preco` com o valor `25`.
2. Utilize `*=` para multiplicar o valor de `preco` por `4`.
3. Imprima `preco`.

Saída esperada:

```
100
```

## Exercício 5

Crie um programa que:

1. Crie a variável `valor` com o número `80`.
2. Utilize `/=` para dividir `valor` por `4`.
3. Imprima `valor`.

Saída esperada:

```
20.0
```

## Exercício 6

Agora vamos praticar a divisão inteira com atribuição.

Crie um programa que:

1. Crie a variável `numero` com o valor `17`.
2. Utilize `//=` para dividir `numero` por `5`, mantendo apenas a parte inteira do resultado.
3. Imprima `numero`.

Saída esperada:

```
3
```

## Exercício 7

Agora vamos usar o operador de resto da divisão com atribuição.

Crie um programa que:

1. Crie a variável `numero` com o valor `17`.
2. Utilize `%=` para guardar na própria variável o resto da divisão de `numero` por `5`.
3. Imprima `numero`.

Saída esperada:

```
2
```

## Exercício 8

Agora vamos praticar a exponenciação com atribuição.

Crie um programa que:

1. Crie a variável `numero` com o valor `3`.
2. Utilize `**=` para elevar `numero` ao quadrado.
3. Imprima `numero`.

Saída esperada:

```
9
```

## Exercício 9

Agora vamos fazer duas atualizações na mesma variável.

Crie um programa que:

1. Crie a variável `saldo` com o valor `100`.
2. Utilize `+=` para adicionar `50` ao saldo.
3. Utilize `-=` para subtrair `30` do saldo.
4. Imprima `saldo`.

Saída esperada:

```
120
```

## Exercício 10

Vamos combinar diferentes operadores de atribuição no mesmo programa.

Crie um programa que:

1. Crie a variável `valor` com o número `20`.
2. Utilize `*= ` para multiplicar `valor` por `3`.
3. Utilize `-= ` para subtrair `10` do resultado.
4. Utilize `/= ` para dividir o resultado por `2`.
5. Imprima `valor`.

Saída esperada:

```
25.0
```
