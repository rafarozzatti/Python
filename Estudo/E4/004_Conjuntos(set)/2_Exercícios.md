# Exercícios de Conjuntos(set)

## Exercício 1

Crie um conjunto chamado `numeros` contendo os seguintes valores:

`10, 20, 30, 40, 50, 10, 20`

Depois:

1. Imprima o conjunto.
2. Imprima o tipo da variável utilizando `type()`.
3. Crie um conjunto vazio chamado `dados`.
4. Imprima `dados` e seu tipo.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-1)

## Exercício 2

Crie o conjunto:

```
frutas = {"Maçã", "Banana", "Uva", "Laranja"}
```

Depois, utilizando `in` e `not in`, faça quatro verificações:

1. Verifique se `"Banana"` existe no conjunto.
2. Verifique se `"Morango"` existe no conjunto.
3. Verifique se `"Uva"` não existe no conjunto.
4. Verifique se `"Abacaxi"` não existe no conjunto.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-2)

## Exercício 8

3. Imprima `resultado`.
4. Imprima `numeros_a` e `numeros_b` para verificar se os conjuntos originais foram mantidos.

## Exercício 10
