# Exercícios de Funções Integradas

## Exercício 1

Considere a seguinte lista:

```
vendas = [150, 200, 350, 100, 250]
```

Crie um código que:

1. Utilize `len()` para descobrir a quantidade de vendas.
2. Utilize `sum()` para calcular o valor total das vendas.
3. Exiba os dois resultados.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-1)

## Exercício 9

```
produtos = ['Notebook', 'Mouse', 'Teclado']
```

```
Mouse - Total: R$ 400
Teclado - Total: R$ 450
```

## Exercício 10

Vamos juntar várias funções que estudamos.

Considere a lista:

```
vendas = [1200.456, 850.789, 2300.123, 1750.567, 950.234]
```

Crie um código que:

1. Utilize `len()` para descobrir a quantidade de vendas.
2. Utilize `sum()` para calcular o total vendido.
3. Utilize `min()` para encontrar a menor venda.
4. Utilize `max()` para encontrar a maior venda.
5. Utilize `round()` para calcular a média das vendas com duas casas decimais.
6. Utilize `sorted()` para ordenar as vendas do maior para o menor.

Exiba todos os resultados.
