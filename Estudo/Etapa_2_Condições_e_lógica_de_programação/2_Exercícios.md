# Exercícios de if, elif e else

## Exercício 1

Crie um programa que:

1. Crie a variável `idade` com o valor `20`.
2. Verifique se a idade é maior ou igual a `18`.
3. Se a condição for verdadeira, exiba `Maior de idade`.

Saída esperada:

```
Maior de idade
```

## Exercício 2
Crie um programa que:

1. Crie a variável `idade` com o valor `15`.
2. Verifique se a idade é maior ou igual a `18`.
3. Se a condição for verdadeira, exiba `Maior de idade`.

Saída esperada: nenhuma mensagem será exibida, pois a condição é falsa.

## Exercício 3

Agora vamos fazer o programa executar uma ação quando a condição for falsa.

Crie um programa que:

1. Crie a variável `idade` com o valor `16`.
2. Se a idade for maior ou igual a `18`, exiba `Maior de idade`.
3. Caso contrário, exiba `Menor de idade`.

Saída esperada:

```
Menor de idade
```

## Exercício 4

## Exercício 10
