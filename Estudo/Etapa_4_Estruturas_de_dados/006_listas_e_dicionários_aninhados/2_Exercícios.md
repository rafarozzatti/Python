# Exercícios de Listas e Dicionários Aninhados

## Exercícios — 1

Crie uma lista chamada `notas` contendo três listas internas, cada uma com três notas de um aluno:

- Primeiro aluno: 8, 7, 9
- Segundo aluno: 6, 8, 7
- Terceiro aluno: 9, 10, 8

Depois, utilize `print()` para exibir:

1. A lista completa.
2. A primeira lista de notas.
3. A segunda nota do segundo aluno.
4. A terceira nota do terceiro aluno.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-1)

## Exercício 2

Utilize a mesma lista `notas` do exercício anterior.

Faça as seguintes alterações:

1. Altere a primeira nota do primeiro aluno para `10`.
2. Altere a terceira nota do segundo aluno para `9`.
3. Exiba a lista completa após as alterações.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-2)

## Exercício 3

Utilize a lista `notas` abaixo:

```
notas = [    
    [8, 7, 9],    
    [6, 8, 7],    
    [9, 10, 8]
]
```

Utilize dois laços `for` para percorrer a lista e imprimir todas as notas, uma por linha.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-3)

Depois, exiba:

1. O dicionário completo.

4. A nota do primeiro aluno.

## Exercício 9

Vamos fazer um exercício um pouco mais completo.

Crie uma lista chamada `vendas` contendo três dicionários, cada um representando uma venda:

- Venda 1: produto Notebook, quantidade 2, valor unitário 3500.
- Venda 2: produto Mouse, quantidade 3, valor unitário 80.
- Venda 3: produto Teclado, quantidade 1, valor unitário 150.

Depois:

1. Exiba o nome do produto da segunda venda.
2. Altere a quantidade da primeira venda para `3`.
3. Adicione uma chave chamada `cliente` na terceira venda, com o valor `Rafael`.
4. Exiba a lista completa após as alterações.

[Resolução](3_Resolução_dos_Exercícios.md#exercício-9)

## Exercício 10

Vamos juntar o que estudamos em um único exercício.

Crie uma lista chamada `funcionarios` contendo três dicionários:

- Carlos: idade 25, salário 3000.
- Mariana: idade 30, salário 4500.
- Pedro: idade 28, salário 3500.

Depois, faça as seguintes operações:

1. Exiba o nome e o salário de cada funcionário utilizando `for`.
2. Altere o salário de Carlos para `3500`.
3. Adicione um novo funcionário chamado Ana, com idade 27 e salário 4000.
4. Exiba a lista completa após as alterações.

Utilize apenas os conceitos que já estudamos: listas, dicionários, acesso por índices e chaves, `append()` e `for`.
