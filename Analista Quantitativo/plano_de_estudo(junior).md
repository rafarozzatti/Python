## **Plano de Estudos para Analista Quantitativo Júnior (4-6 meses)**  

### **🔹 Fase 1: Fundamentos Essenciais (1-2 meses, intensivo)**  
📌 **Objetivo**: Aprender o básico necessário para modelagem quantitativa.  

✅ **Matemática e Estatística Aplicada (2-4 semanas)**  
- Álgebra Linear: Matrizes, autovalores, sistemas lineares.  
- Probabilidade e Estatística: Distribuições, testes de hipótese.  
- Séries Temporais: ARIMA, regressão linear.  

✅ **Python para Finanças (2-4 semanas)**  
- Pandas, NumPy e Matplotlib para análise de dados financeiros.  
- SQL para consultas de bancos de dados.  
- Backtesting de estratégias com *Backtrader*.  

📌 *Recursos*:  
- Curso: *"Python for Data Analysis" – Wes McKinney*  
- Curso: *"Mathematics for Machine Learning" – Coursera*  

---

### **🔹 Fase 2: Finanças Quantitativas e Modelagem (2 meses, paralela à Fase 1)**  
📌 **Objetivo**: Construir modelos financeiros básicos e entender estratégias quantitativas.  

✅ **Mês 1:**  
- Introdução aos mercados financeiros (ações, opções, derivativos).  
- Modelagem Quantitativa: CAPM, Value at Risk (VaR).  
- Implementação de regressão linear para prever preços.  

✅ **Mês 2:**  
- Estratégias de trading algorítmico: Momentum, Mean Reversion.  
- Machine Learning básico aplicado a finanças: XGBoost para previsão de preços.  
- Backtesting e otimização de estratégias.  

📌 *Recursos*:  
- Curso: *"Algorithmic Trading in Python" – Udemy*  
- Livro: *"Quantitative Finance for Dummies" – Steve Bell*  

---

### **🔹 Fase 3: Projeto Final e Portfólio (1-2 meses)**  
📌 **Objetivo**: Criar projetos para GitHub e se preparar para entrevistas.  

✅ **Mês 1:**  
- Criar um algoritmo de previsão de preços com ML.  
- Backtest de uma estratégia quantitativa.  
- Análise de risco e otimização de portfólio.  

✅ **Mês 2:**  
- Preparação para entrevistas técnicas.  
- Aplicação para vagas júnior.  

📌 *Recursos*:  
- Desafios no *Kaggle* e *Numerai*.
