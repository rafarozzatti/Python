## Estrutura de Repetição FOR

#### Exemplo sem o FOR:

```python
n1 = int(input('Digite um valor: '))
n2 = int(input('Digite um valor: '))
n3 = int(input('Digite um valor: '))
n4 = int(input('Digite um valor: '))
n5 = int(input('Digite um valor: '))
n6 = int(input('Digite um valor: '))
n7 = int(input('Digite um valor: '))
n8 = int(input('Digite um valor: '))
n9 = int(input('Digite um valor: '))
n10 = int(input('Digite um valor: '))
```

#### Exemplo com o FOR:

```python
for c in range(0, 10):
    n1 = int(input('Digite um valor: '))
# esse código executa a mesma coisa que o código anterior
```
