## Listas (Parte 2)


#### Exemplos:

```python
pessoas = [['Pedro', 25], ['Maria', 19], ['João', 32]]
print(pessoas[0][0])
# Resultado: Pedro
```

```python
pessoas = [['Pedro', 25], ['Maria', 19], ['João', 32]]
print(pessoas[1][1])
# Resultado: 19
```

```python
pessoas = [['Pedro', 25], ['Maria', 19], ['João', 32]]
print(pessoas[2][0])
# Resultado: João
```

```python
pessoas = [['Pedro', 25], ['Maria', 19], ['João', 32]]
```
