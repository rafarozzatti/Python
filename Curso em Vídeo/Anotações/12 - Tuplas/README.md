## Tuplas


#### Exemplos:

```python
lanche = ('Sanduiche', 'Suco', 'Pizza', 'Pudim')
print(lanche[2])
# Resultado: 'Pizza'
```

```python
lanche = ('Sanduiche', 'Suco', 'Pizza', 'Pudim')
print(lanche[0:2])
# Resultado: 'Sanduiche' e 'Suco'
```

```python
lanche = ('Sanduiche', 'Suco', 'Pizza', 'Pudim')
print(lanche[1:])
# Resultado: 'Suco', 'Pizza' e 'Pudim'
```

```python
lanche = ('Sanduiche', 'Suco', 'Pizza', 'Pudim')
print(lanche[-1])
# Resultado: 'Pudim'
```

```python
lanche = ('Sanduiche', 'Suco', 'Pizza', 'Pudim')
print(len(lanche))
# Resultado: '4'
```
